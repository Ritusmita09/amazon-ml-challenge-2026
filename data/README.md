# Data Directory

The original Amazon ML Challenge 2026 dataset is **not included** in this GitHub repository due to file size constraints and competition rules regarding the distribution of proprietary data. 

To run this pipeline, the original datasets must be obtained through the competition platform if permitted, and placed inside a `dataset/` directory before execution. No dataset files, SQLite databases, candidate generations, SQLite backups, parquet formats, or compiled matching outcomes are hosted in this public repository.
